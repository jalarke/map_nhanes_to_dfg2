# Map NHANES to DFG2

This project maps food text descriptions from NHANES 24-hr dietary recalls to foods in the Davis Food Glycopedia (DFG2) database. The resulting labels identify which NHANES ingredients have a corresponding DFG2 entry, enabling downstream analysis of food glycans at the population level. This labeled set of matches and non-matches serves as a benchmark dataset that has been used to evaluate the use of Large Language Models for automated methods in mapping dietary data to food databases.  

## Overview

The pipeline takes individual-level dietary recall data from NHANES, extracts a unique list of food ingredients, and attempts to match each ingredient to a food in the DFG2 reference database using TF-IDF fuzzy text matching. Matches are then manually reviewed before producing a final labeled dataset.

The pipeline consists of three scripts run in order:

1. **`01_build_nhanes_dataset.py`** — Loads raw NHANES dietary recall data, filters to adults (18+), recodes demographic variables (education, sex, BMI, blood pressure, smoking status), and outputs a unique list of food ingredients.
2. **`02_text_match_nhanes_to_dfg2.py`** — Cleans ingredient text (removes punctuation/stopwords, lemmatizes via NLTK WordNet) and runs TF-IDF fuzzy matching against the DFG2 food list using `polyfuzz`.
3. **`03_clean_matches_and_label.py`** — Processes the manually curated match file, merges accepted matches with DFG2 food data, and outputs a final labeled CSV.

## Input Data

Script 1 requires `data/nhanes/wweia_all_recalls.txt`, which is generated by the [wweia_ingredients](https://github.com/jalarke/wweia_ingredients) repository. Follow the instructions there to produce this file and place it at `/data/nhanes/` path before running the pipeline.

Additional NHANES exam and questionnaire data (BMI, blood pressure, smoking status, etc.) are fetched directly from CDC URLs at runtime.

## Manual Curation Step

After running script 2, the file `data/text_match/nhanes_to_dfg2_tfidf_matches.csv` was manually reviewed before script 3 with the following steps:

1. Add a `match` column — set to `n` to reject an matches that are not appropriate
2. Add a `replace` column — provide a `simple_name` from `dfg_foods.csv` to substitute a different match
3. Save as `data/text_match/nhanes_to_dfg2_manually_matched.csv`

## Requirements

- [Conda](https://docs.conda.io/en/latest/) (Miniconda or Anaconda)
- Python dependencies are managed via `environment.yml`:
  - `pandas`
  - `numpy`
  - `scikit-learn`
  - `nltk`
  - `polyfuzz`

## Setup and Usage

**1. Clone the repository and create the environment:**

```bash
git clone https://github.com/jalarke/map_nhanes_to_dfg2
cd map_nhanes_to_dfg2
conda env create -f environment.yml
conda activate map_nhanes_to_dfg2
```

**2. Generate the NHANES input file** using [wweia_ingredients](https://github.com/jalarke/wweia_ingredients) and place it at `data/nhanes/wweia_all_recalls.txt`.

**3. Run the pipeline:**

```bash
bash pipeline.sh
```

The script will pause after step 2 to allow for manual curation before proceeding to step 3.

Alternatively, run each script individually:

```bash
cd src
python 01_build_nhanes_dataset.py
python 02_text_match_nhanes_to_dfg2.py
# perform manual curation (see above)
python 03_clean_matches_and_label.py
```

**Output:** `data/labels/nhanes_dfg2_labels.csv` — each NHANES ingredient with a `label` of `1` (matched to DFG2) or `0` (no match).

See our publication: "Evaluation of Large Language Models for Mapping Dietary Data to Food Databases", when it becomes available.
